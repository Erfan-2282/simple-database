# Simple Database

A simple command-line program that uses a Python dictionary as an in-memory database.

## Features

* Add a new key and value
* Change an existing value
* Delete a key
* Clear the database
* Search for a value
* Show all keys
* Show all values
* Show the full database
* Quit the program

## Requirements

* Python 3.x
* No external packages are required.

## Note

This project is a simple learning project created to practice working with dictionaries, loops, conditions, user input, and basic CRUD operations.
